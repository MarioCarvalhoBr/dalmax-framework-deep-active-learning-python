# A100 full campaign (2026-09-29)

One clean re-execution of **everything the three papers need**, on one execution environment
(Google Colab Pro, A100), same seeds `{1,2,3}`, same protocol, **no redundant run**: every
distinct configuration runs exactly once and every table of every paper points to that single run.
Decision record: ADR 0008 (manifest + dedup) and ADR 0009 (shared "w/o representation" run).
Single source of truth: `files_config/campaign/manifest.json` (generated by
`scripts/campaign/build_manifest.py`; micro mirror `manifest_micro.json`); engine
`dalmax/campaign.py`; reports `dalmax/reporting/campaign_report.py`.

## Protocol (unchanged from the thesis paper-1 chapter)

`n_init_labeled = 100`, `n_round = 8`, `n_epoch = 10`, batch 256, lr 0.05, momentum 0.3
(`files_config/campaign/params_paper1.json` = the DANINHAS block of
`files_config/benchmark/params_df_gpu_0.json`), hierarchy `[600,200,100]` / `sample_sizes [30,15,2]`,
SSRAE `q=13`, VCTex `q=(5,17)`. Fixed test set; the pool is the 8,086 training images. There is
**no validation split** in this project's protocol (pool/test only, as in the thesis) and none is
invented here, including for the upper bound.

## What runs (192 runs, 64 run groups)

| Part | Groups x seeds | Runs | Content |
|---|---|---|---|
| `paper1` | 39 x 3 | 117 | 12 classical strategies x nq {10,50,100} (36 groups, 108 runs) + KMH x nq {10,50,100} (3 groups, 9 runs) |
| `upper_bound` | 1 x 3 | 3 | `FullSupervised`: train once on the entire pool (8,086), evaluate on the test set |
| `rnhal` | 14 x 3 | 42 | paper 3 ablations at nq=100: 6.1 spatial/spectral; 6.2 five existing + five new hierarchy rows; 6.3 full + w/o hierarchical |
| `texhal` | 10 x 3 | 30 | paper 2 ablations at nq=100: 6.1 q5/q13/q17; 6.2 L1/L2a/L2b/L3/L4; 6.3 w/o hierarchical; plus `shared/texhal_full` |
| **Total** | **64 x 3** | **192** | |

Paper 1 = the 12 classical strategies (RandomSampling, LeastConfidence, MarginSampling,
EntropySampling, LeastConfidenceDropout, MarginSamplingDropout, EntropySamplingDropout,
KMeansSampling, KCenterGreedy, BALDDropout, AdversarialBIM, AdversarialDeepFool) + **KMH** + the
upper bound. RNHAL (SSRAE) and TexHAL (VCTex) are **not** in paper 1 (they are papers 3 and 2); the
`SSRAEKmeansHCSampling`/`VCTexKmeansHCSampling` presets at nq 10/50 are dropped.

**KMH (confirmed by the user 2026-09-29)**: plain hierarchical k-means selection over
ImageNet-pretrained ResNet-50 features (`resnet_imagenet`, `q: null`, no SSRAE/VCTex), reference
hierarchy `[600,200,100]/[30,15,2]` -- a Vo et al. (2024)-style baseline. Params:
`files_config/campaign/params_kmh.json`. Shown in paper-1 tables as "KMH (hierarchical k-means,
ImageNet ResNet-50 features)".

**Upper bound = `FullSupervised`** (registered strategy, *not* active learning): labels the ENTIRE
pool at initialization (`n_init_labeled` is forced to the pool size; a different CLI value is
overridden with a logged warning, and the recorded config/results dir read `NIL_<pool>`), runs
round 0 only (`ConfigError` unless `--n_round 0`), `query()` raises. Seeds {1,2,3}; artifacts as any
run (one round in `results.json`). Verified on the micro dataset (pool 806): `NIL_806_NR_0`, one
round.

Ownership rule: a group consumed by **more than one paper lives under `shared/`**; every other
group under its paper; `used_by` in the manifest lists every consumer. The previous
"duplicate by explicit decision" exception (2026-09-01, `stage_no_representation` per paper) was
**reversed** (ADR 0009): the redundancy checker (`dalmax.campaign.find_redundant_groups`, enforced in
`validate_manifest` and `tests/test_campaign.py`) has no exceptions, and rejects an alias whose
effective config differs from its canonical group. The manifest has 9 alias rows, i.e. 27 runs (9 x 3 seeds) that a
per-paper plan would have executed again.

Preset vs `RepresentationStrategy` equivalence (checked before the scope change, kept for the
record): on the micro dataset (CPU, seed 1, nq 5, nr 1) `SSRAEKmeansHCSampling` (params with
`config_kmh`) and `RepresentationStrategy` (`rnhal/micro/stage_full.json`) gave identical round-1
query indices (`[34, 67, 119, 237, 522]`) and identical metrics; same for VCTex
(`[158, 291, 384, 393, 538]`). Canonical is now the `RepresentationStrategy` `stage_full` run.

## Commands

```bash
make campaign-list                        # job table + counts per part
make campaign-run PART=all                # everything, skip-existing (re-run = resume)
make campaign-run PART=paper1|upper_bound|rnhal|texhal   # or comma-separated
make campaign-verify                      # OK/INCOMPLETE/MISSING per job + seed-consistency audit
make campaign-report                      # docs/results/campaign_a100/ (tables md/tex/csv, confusion matrices)
make campaign-smoke                       # micro campaign on CPU (seed 1, 64 jobs) -> results/smoke_campaign/
```

`python -m dalmax.campaign {list,run,verify} --part ... [--micro] [--seeds 1] [--dry-run]
[--no-skip-existing] [--device cuda]`. Execution order (independent of `--part`): paper 1 at nq100
first (the shared canonical runs land early), then rnhal, texhal, then paper 1 at nq50 and nq10,
then the upper bound -- what is missing if a budget runs out is the least reusable part. Papers 2/3
comparison tables need paper 1's `shared/*` runs and `shared/texhal_full`: run those parts before
reporting.

## Seeds and determinism

`seed_everything` seeds Python/NumPy/PyTorch, sets cudnn deterministic (benchmark off),
`CUBLAS_WORKSPACE_CONFIG=:4096:8` and `torch.use_deterministic_algorithms(True, warn_only=True)`;
`run_metadata.json` records a `determinism` block (seed, algorithms flag, cudnn flags, cuBLAS
config). Guarantees: identical seeds give identical initial labeled sets, selection randomness and
data order; bit-identical metrics on CPU (golden tests) and on the same GPU model/driver; **not**
across different GPU models. `campaign verify` runs the **seed-consistency audit**: for each seed,
the `Initial labeled idxs (sorted)` line of every run's `log-dalmax.log` (all strategies/configs;
`FullSupervised` excluded) must be identical -- PASS/FAIL per seed with the offenders listed.

## Which paper table each group feeds

Exactly the manifest's `tables` section (paper 1: one table per nq with the 12 + KMH + upper-bound
rows; papers 2/3: 6.1/6.2/6.3 + comparison; paper 2 comparison = TexHAL-full vs best paper-1 method
@100 (12 classical + KMH, computed, name printed) vs RandomSampling@100; paper 3 comparison =
RNHAL-full vs TexHAL-full vs RandomSampling@100 + best paper-1 @100 as context). Rows without runs
render `TBD`. `docs/results/campaign_a100/summary.csv` lists every (paper, table, row) with its
resolved run.
